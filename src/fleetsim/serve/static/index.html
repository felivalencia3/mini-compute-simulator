    fleetsim

    Local mission control for the fleet simulator.

    • Pick a run on the left to open its interactive 2D report.
    • New run opens the scenario editor: validate YAML, launch, watch live progress.
    • compare in the rail header selects runs (shift-click for a range) — 2 or more open the compare view: metric matrix, overlaid timelines, config diff.
    • Explore… sweeps a parameter grid — one run per cell, then compare the cells.
    • Validation shows every published number fleetsim is measured against — including what it deliberately does not reproduce.
    • Runs finished from the CLI into this workspace show up here too.
